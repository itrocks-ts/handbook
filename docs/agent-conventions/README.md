# Agent conventions

When creating or updating instructions for AI agents:

- State only project-specific directives; omit tasks an AI agent already knows how to perform.
- Check existing guides for repetition and link to the authoritative rule instead of copying it.
- Keep wording minimal, clear and understandable by both AI agents and human readers.
- Put each rule in the guide for its task and update the routing link when adding a guide.

Follow [documentation conventions](../framework-changes/documentation/markdown.md).
